# SceneKit Demo

A small iOS project for experimenting with **SceneKit** and learning the fundamentals of working with 3D content on Apple platforms.

The repository is intended as a playground for exploring SceneKit concepts rather than a production application.

## Overview

This project was created to practice working with 3D scenes and understand how SceneKit represents and renders content.

It serves as a reference project for experimenting with concepts such as:

- 3D scenes
- Scene nodes
- Cameras
- Lighting
- Materials
- Scene transformations
- Basic 3D interactions
- SceneKit rendering

## Tech Stack

- Swift
- iOS
- SceneKit
- Xcode

## Running the Project

Clone the repository:

```bash
git clone https://github.com/himanshu240601/SceneKitDemo.git
cd SceneKitDemo
```

Open the project in Xcode:

```bash
open SceneKitDemo.xcodeproj
```

Select an iOS simulator or physical device and run the application.

## What I Practiced

This project helped me explore:

- SceneKit scene hierarchy
- Working with `SCNScene`
- Managing `SCNNode` objects
- Positioning 3D content
- Cameras and viewpoints
- Lighting and materials
- Basic 3D transformations
- Rendering SceneKit content on iOS
